  多巴胺日历 — 安卓手机安装指南
══════════════════════════════════════════

📱 方式一：浏览器直接打开（最简单）

  1. 把整个 dopamine-calendar 文件夹传到手机上
     （微信/QQ/数据线 都可以）
  2. 用手机文件管理器找到 index.html
  3. 用 Chrome 浏览器打开
  4. 点击 Chrome 菜单(⋮) → "添加到主屏幕"
  5. 桌面出现「多巴胺日历」图标，点击即用！

  ⚠ 注意：部分手机从本地文件添加时不会弹出安装提示，
     可尝试方式二获得完整体验。


📱 方式二：HTTP 服务器安装（推荐，完整体验）

  ⭐ 最简单：用「HTTP 快捷方式」App（Play 商店免费）

  1. 安装 "Simple HTTP Server" 或类似 App
  2. 选择 dopamine-calendar 文件夹
  3. 启动服务器
  4. 在 Chrome 中打开显示的地址(如 http://192.168.1.5:8080)
  5. 会自动弹出安装提示 → 点击安装
  6. 桌面出现独立 App 图标！


📱 方式三：上传到网络空间

  如果你有自己的网站空间或使用 GitHub Pages：

  1. 上传整个文件夹到服务器
  2. 用手机 Chrome 打开网址（需要 HTTPS）
  3. 自动弹出安装提示 → 点击安装
  4. 成为真正的手机 App！


══════════════════════════════════════════
  PWA 特性：安装后支持离线使用、全屏显示、
  无浏览器 UI，体验与原生 App 一致。
