# 多巴胺日历 — 安装指南

网址：https://janezhao200302-del.github.io/dopamine-calendar/

---

## Windows 电脑

### 方式一：PWA 安装（推荐）

1. Edge 或 Chrome 打开上面网址
2. 地址栏右侧出现安装图标 → 点击 → **安装**
3. 桌面出现「多巴胺日历」图标，双击打开，全屏无边框

### 方式二：双击启动器

双击 `launch.vbs`，以独立窗口打开。

### 方式三：桌面快捷方式

右键桌面 → 新建快捷方式 → 填入：
```
"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --app="https://janezhao200302-del.github.io/dopamine-calendar/?v=999"
```
下一步 → 命名「多巴胺日历」→ 完成

---

## Android 手机

1. **Chrome** 打开网址
2. 点右上角 ⋮ → **添加到主屏幕**（或「安装应用」）
3. 桌面出现图标，全屏运行

> 如果没有安装提示，等几秒地址栏会出现安装横幅

---

## iPhone / iPad

1. **Safari** 打开网址
2. 点底部 **分享** 按钮（方框+箭头）
3. 滑动找到 **「添加到主屏幕」**
4. 命名 → 添加
5. 桌面出现图标

---

## Mac 电脑

1. Chrome 或 Edge 打开网址
2. 地址栏右侧安装图标 → 安装
3. 程序坞出现图标

---

## 同步

所有设备登录后输入 **相同同步码**，数据自动同步。
